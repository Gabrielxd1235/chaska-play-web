# Chaska Play · página web

Página de presentación de **Chaska Play**, la app que convierte leyendas, comida y tradiciones del Perú en retos de programación con bloques para jóvenes de 10 a 17 años.

Proyecto del curso Marketing y Comercialización de Nuevos Productos (Tecsup, Arequipa).

Sitio estático de un solo archivo (`index.html`), publicado en Render como *Static Site* (sin comando de build, carpeta de publicación `.`).
